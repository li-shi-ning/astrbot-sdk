# 指令接口

指令接口用于处理用户输入的命令，是插件最常见的入口。

## 适用场景

- 需要显式触发的功能（如 `/help`、`/todo`）
- 参数化操作（如 `/echo xxx`）
- 子命令结构（如 `/math add 1 2`）

## 常见接口形态

### 1) 普通指令

```python
from astrbot.api.event import filter

@filter.command("hello")
async def hello(self, event):
    yield event.plain_result("Hello, AstrBot!")
```

### 2) 指令别名

```python
@filter.command("help", alias={"帮助", "helpme"})
async def help_cmd(self, event):
    yield event.plain_result("这里是帮助信息")
```

### 3) 指令组与子指令

```python
@filter.command_group("math")
async def math(self, event):
    pass

@math.command("add")
async def math_add(self, event, a: int, b: int):
    yield event.plain_result(str(a + b))
```

## 实践建议

- 指令名尽量短、语义明确。
- 对用户输入做参数校验，避免异常直接暴露。
- 对长耗时任务及时返回处理中状态，提升体验。
