# 消息发送接口

消息发送接口用于把文本、图片等内容返回给用户。

## 适用场景

- 快速回复文本
- 发送结构化内容（图片、合并消息等）
- 根据平台能力选择不同发送策略

## 常见接口形态

### 1) 文本回复

```python
yield event.plain_result("操作成功")
```

### 2) 组合回复

```python
yield event.plain_result("任务完成")
# 如需扩展，可继续拼接图片/文件等消息段
```

## 实践建议

- 先保证文本可用，再逐步扩展富媒体。
- 对平台差异做降级方案（不支持的消息类型回退到文本）。
- 对失败发送做好重试与错误提示。
