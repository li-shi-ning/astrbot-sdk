# 事件接口

事件接口用于监听系统或消息生命周期中的关键节点，适合做“被动响应”。

## 适用场景

- 监听消息并做预处理/审计
- 在特定平台下执行差异化逻辑
- 对某类消息做统一策略

## 常见接口形态

### 1) 消息事件

```python
async def on_message(self, event):
    # 在这里处理非指令型消息
    ...
```

### 2) 事件筛选装饰器

```python
from astrbot.api.event import filter

@filter.event_message_type("group")
async def on_group_message(self, event):
    ...
```

## 实践建议

- 事件处理函数中尽量保持“轻逻辑”，重逻辑交给服务层。
- 对可重复触发的事件做好幂等处理。
- 避免和指令路由冲突：要明确一个行为由“指令”还是“事件”驱动。
