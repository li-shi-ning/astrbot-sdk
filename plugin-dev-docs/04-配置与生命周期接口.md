# 配置与生命周期接口

配置与生命周期接口决定了插件如何被加载、初始化和管理。

## 适用场景

- 声明插件元信息
- 管理插件依赖
- 控制插件启动时行为

## 关键文件与接口

### 1) `metadata.yaml`

用于声明插件基础信息（名称、描述、平台支持、版本约束等）。

建议重点维护字段：

- `display_name`
- `support_platforms`
- `astrbot_version`

### 2) `requirements.txt`

声明插件依赖，确保用户安装插件时可以自动拉取必需库。

## 生命周期实践建议

- 初始化阶段仅做必要操作，避免阻塞加载流程。
- 将持久化数据放在 `data` 目录，避免插件重装时丢失。
- 发布前检查依赖与版本约束是否完整。
