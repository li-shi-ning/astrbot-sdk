# 插件开发文档（按接口类别）

> 参考：`docs/zh/dev/star/plugin-new.md`

为了便于按“接口能力”快速查阅，这里将插件开发内容拆分为以下类别文档：

1. [消息与指令接口](./01-message-and-command.md)
2. [会话与状态接口](./02-session-and-state.md)
3. [消息输出与媒体接口](./03-output-and-media.md)
4. [AI 与工具接口](./04-ai-and-tool.md)
5. [工程化与发布接口](./05-project-and-release.md)

## 适用场景

- 你已经了解基础插件结构，但希望按能力面向查 API。
- 你在做特定功能（如会话控制、文转图、LLM Tool）时想快速定位示例。
- 你希望把 `plugin-new.md` 的起步信息和 `guides/` 的专题信息串起来看。

## 使用建议

- 首次开发：先看 `05`（工程化）+ `01`（最小可跑通链路）。
- 增强交互：重点看 `02`（会话）+ `03`（输出）。
- 智能体能力：重点看 `04`（AI/Tool）。
