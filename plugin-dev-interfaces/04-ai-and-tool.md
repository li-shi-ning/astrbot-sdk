# 04 AI 与工具接口

## 获取当前会话模型

当插件希望复用当前会话配置时，可先读取 `provider_id`。

## 直接调用 LLM

通过 `context.llm_generate(...)` 可完成基础补全调用。

## Tool 扩展

可通过定义 Tool（函数工具）让模型在对话中调用外部能力（检索、查询、业务 API）。

推荐流程：

1. 定义 Tool 的名称、描述、参数 schema。
2. 实现 `call(...)` 逻辑并返回结果。
3. 在插件初始化阶段注册到上下文（`add_llm_tools(...)`）。

## 适用场景

- 需要“先思考再调用工具”的智能体插件。
- 多数据源聚合回答。
- 结构化任务执行（查询、统计、生成）。
