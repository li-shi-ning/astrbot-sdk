# AI 能力接口

本页聚焦插件中与模型能力相关的常用接口与用法。

## 适用场景

- 在插件中调用 LLM 进行问答、改写、总结。
- 结合工具调用、多 Agent 协作实现复杂流程。
- 在业务流程中按需引入模型能力，而非全局依赖。

## 使用建议

- 将“Prompt 组装”与“业务流程”解耦，方便调试和测试。
- 对模型调用加入超时、重试、降级策略。
- 对关键上下文做长度控制，避免无效 token 消耗。
