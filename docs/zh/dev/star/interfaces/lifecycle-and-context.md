# 生命周期与上下文接口

本页关注插件启动、卸载、资源释放等生命周期问题。

## 核心关注点

- `Star` 子类初始化：通过 `Context` 获取运行时能力。
- `terminate()`：插件卸载/停用时释放资源。
- 异常处理：避免单次失败导致插件整体不可用。

## 工程建议

- 在初始化阶段完成依赖可用性检查。
- 对后台任务（轮询、定时任务）建立统一取消机制。
- 在 `terminate()` 中关闭连接、清理任务、刷新缓存。
