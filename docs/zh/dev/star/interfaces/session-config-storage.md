# 会话、配置与存储接口

本页用于说明插件工程化开发中最常见的状态管理接口。

## 接口类别

- 会话控制：会话隔离、上下文重置、生命周期管理。
- 插件配置：读取配置、默认值设计、热更新策略。
- 数据存储：持久化插件数据，避免写入插件源码目录。
- 环境变量：密钥、开关等运行时参数管理。

## 实践建议

- 持久化数据统一存到 `data` 目录。
- 配置项区分“必填”和“可选”，并给出明确报错。
- 对外部资源配置（API Key、URL）提供启动时自检。
